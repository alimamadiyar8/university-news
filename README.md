\# Университет жаңалықтары



\## Сипаттамасы

Университет жаңалықтарын сақтауға және көрсетуге арналған қарапайым Python қосымшасы.



\## Қолданылатын технологиялар

\- Python 3.11

\- pytest

\- GitHub Actions



\## Орнату

pip install -r requirements.txt



\## Іске қосу

python src/app.py



\## Тестілеу

pytest tests/ -v



\## CI/CD

GitHub Actions арқылы әрбір push кезінде автоматты түрде:

1\. Тәуелділіктер орнатылады

2\. Жоба құрастырылады (Build)

3\. Тестілер іске қосылады (Test)
